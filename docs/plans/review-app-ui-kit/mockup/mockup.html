Retry timed-out requests until a total deadline

The existing strategy owns timeout retries, and a total deadline bounds every retry sequence.

// Bounded by the total deadline
export class RequestRetryStrategy {
  shouldRetry(error, attempt) {
    return attempt < 3 && error.name === "TimeoutError";
  }
}
